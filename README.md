# Enyuan Zhao — Personal Academic Homepage

Minimal, Jon Barron-style academic homepage.

## Files

- `index.html` — English version (default homepage)
- `index-zh.html` — Chinese version

## Before publishing

1. Open `index.html` and `index-zh.html`.
2. Replace the placeholder email `you@ucas.ac.cn` with your real address (search for `TODO`).
3. Optionally add a photo and GitHub / LinkedIn links.

## Publish to GitHub Pages (free)

1. Create a repository named `<your-username>.github.io` on GitHub (public).
2. Upload `index.html`, `index-zh.html`, and this `README.md` to that repository.
3. GitHub Pages will automatically publish it at `https://<your-username>.github.io` within a few minutes.

Alternatively, use git:

```bash
git init
git add .
git commit -m "Initial academic homepage"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
git push -u origin main
```
